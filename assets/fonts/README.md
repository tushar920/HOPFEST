# Heading font

Headings are set to use **Neutronic Heavy**. It's a licensed font (Hypertype, via Adobe Fonts / Future Fonts),
so it isn't committed here. To switch it on, add your licensed web font file to this folder as:

- `Neutronic-Heavy.woff2` (preferred), or
- `Neutronic-Heavy.otf`

Until then, headings fall back to Archivo (heavy weight) from Google Fonts.

# Heading font: Neutronic Heavy

Headings use **Neutronic Heavy** (Hypertype, via Adobe Fonts). Subheadings use Inter Bold and body text Inter Regular (Inter is already built into the page).

To switch Neutronic on, either:

1. **Adobe Fonts (recommended):** create a Web Project containing Neutronic Heavy, add `tushar920.github.io` as an allowed domain, and paste the project's
   `<link rel="stylesheet" href="https://use.typekit.net/XXXXXXX.css">` line into `index.html` where the comment says so; or
2. **Self-host:** if your licence allows it, put `Neutronic-Heavy.woff2` (or `.otf`) in this folder.

Until then, headings fall back to a heavy, slightly wide Archivo from Google Fonts.

# HOP FEST photography handoff

The page deliberately references local, production-ready asset paths instead of using placeholder photography. Add optimised `.jpg` or `.webp` files at the following locations. The exact filenames are used by `index.html`.

| Path | Expected composition |
| --- | --- |
| `hero/hero-kids-race.jpg` | Main 4:3 hero: several Indian children sprinting/jumping in a lively event setting. |
| `hero/hero-finish-line.jpg` | Portrait finish-line celebration. |
| `kids/kids-sprint.jpg` | Portrait running moment. |
| `kids/kids-play.jpg` | Active candid play. |
| `kids/kids-celebrate.jpg` | Child celebrating after a challenge. |
| `sports/race-zone.jpg` | Tall race activity. |
| `sports/challenge-zone.jpg` | Obstacle-course moment. |
| `sports/play-zone.jpg` | Football / active game. |
| `sports/ultimate-hop-challenge.jpg` | Main challenge shot with speed, course and cheering. |
| `family/parent-child-high-five.jpg` | Parent and child high-five. |
| `family/family-race.jpg` | Family participating together. |
| `family/family-laughing.jpg` | Candid family moment. |
| `family/together-zone.jpg` | Shared family activity. |
| `event/explore-zone.jpg` | Children exploring an activity zone. |
| `event/final-celebration.jpg` | Wide finale: kids running/jumping/celebrating with festival atmosphere. |

Use candid, contemporary Indian event photography—real motion, imperfect moments, colour and physical energy. Avoid posed stock photos. Keep the hero/final photos at least 1800px wide, all other images at least 1000px on their longest side, and compress them for web delivery.
